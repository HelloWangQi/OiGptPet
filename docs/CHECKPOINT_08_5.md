# 0.8.5 检查点：工坊独立滚动与绘制监测

2026-11-03。用户要求继续开发，期间指出右侧区域不应把整页撑高。本阶段合并完成布局修正、绘制采样和原生隐藏暂停，保存本地提交后暂停；没有推送或发布 GitHub。

## 交付

- 桌面工坊高度约束为当前视口，页头/页脚固定在布局中。右侧设置使用独立滚动条，滚到底不带动整页；左侧角色、动作区和状态保持原位。视口改变后预览随可用高度伸缩，极短视口左栏可自行滚动；宽度不超过 780px 的单列网页保留原页面滚动。右栏可键盘聚焦。
- `RenderMonitor` 统计完成的 stage.render 调用，通常每两秒报告；少于 500ms、空角色或隐藏不生成 FPS，没绘制的有效可见采样为 0。最多保存最近 256 个同步调用耗时，报告均值/P95 和实际数量。性能档、互动状态、暂停状态、角色类型或成功换角色时清零。
- 工坊只显示本窗口数据；桌宠独立采样，JSON 诊断按窗口记录。主进程验证调用窗口归属并白名单复制字段，忽略额外字段，拒绝坏数值；不存在账号、角色名、聊天或路径字段。每个渲染窗口最多一个上报请求在途，没有队列累积。
- 采样缓存使用单调时钟，超过 10 秒标为 stale；窗口隐藏时诊断返回 hidden/null，刷新、关闭、渲染进程退出和重新显示会清缓存。隐藏时停止周期上报。
- 隐藏暂停同时参考页面状态和原生窗口 hide/show。只读 IPC 返回调用窗口本身的可见性；先订阅再读取初始状态，用事件序列丢弃迟到初始值。隐藏停止绘制，恢复重置帧调度并开始新采样。

详细字段和边界见 [DESKTOP_DIAGNOSTICS.md](DESKTOP_DIAGNOSTICS.md)，更新说明见 [v0.8.5](releases/v0.8.5.md)。本轮没有改变原有画质/均衡/省电的帧率上限。

## 验证证据

- `npm test`：32 个文件、385 项通过。
- 最终 EXE：`release/v0.8.5-1793697248931/OiGptPet-win32-x64/OiGptPet.exe`，由当前源码运行 `npm run verify:desktop` 生成。
- 最终基础结果：`artifacts/release-smoke/run-1793697254159/result.json`；先前同运行时代码的预检 `run-1793697137342/result.json` 已通过，不混作最终包的结果。
- 新增布局检查在 1220×850、980×700、1440×900 内容尺寸下调整真实测试窗口，验证右栏高度在视口内、存在内部滚动、滚到尾部左侧预览位置/高度不变、页面 scrollY=0，末尾滚轮不传到页面。三张 workshop-sidebar 截图保存在结果目录，正常及小尺寸截图已人工查看。
- 新增 EXE 采样检查验证省电互动上限 15、画质互动上限 60、省电闲置上限 5 下的实际非零绘制频率，验证两个窗口各自的均值/P95 和新鲜度；保存 render-battery/idle/hidden/resumed.json。
- 通过实际宠物 Canvas2D drawImage 计数，原生隐藏稳定后 700ms 绘制增量为 0，显示恢复后计数继续增加、收到新的 active 采样；在 Page Visibility 被自动化环境影响的情况下仍验证此行为。原生隐藏诊断返回 null，不伪造 FPS=0。
- 复验空模型首次启动、VRM/精灵图角色库、身体拖动、设置持久化、聊天流式/取消/重试/重开、动作适配的三个导出报告及切换清理；这些服务请求均为模拟。
- 本地包保留脚本自动执行，保留最近三个已识别包。模型、原始资源和测试产物不随分发包提交。

预检中发现独立窗口尚未上报、工坊实际隐藏，以及原生可见性与页面可见性不一致等条件，已分别修正等待前提和原生隐藏接线。失败运行不算通过证据；最终结果以上述新包编号为准。Electron 的后台节流会影响 Page Visibility，不能假定自动化里的 document.hidden 代表原生状态：[Electron 文档](https://www.electronjs.org/docs/latest/api/browser-window#page-visibility)。

## 范围与后续

EXE 检查请求 SwiftShader 软件后端；采样衡量绘制调用和同步墙钟耗时，不证明显示器呈现 FPS、纯 CPU 时间、GPU 完成时间、显存或能耗达标。没有改门槛或强制 GC，也没有重跑满小时；0.8.2 的软件增长提示及 Intel/D3D11 对照仍保留原结论。

真实账户 API、物理多屏/DPI/休眠、更多角色连续动作视觉 QA、ChatGPT 官方入口预检/安装和更多设备性能仍待实际环境。新布局的窗口尺寸检查也不替代物理 DPI 或多屏验收。
