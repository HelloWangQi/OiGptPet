# 桌面诊断与实机记录

在 Windows 桌面版工坊的“陪伴设置”中选择“保存桌面诊断”，选择本地 JSON 文件。网页模式不显示此入口。取消不创建文件；保存失败后可以重试。同一时间只打开一个诊断保存对话框。

报告在选择路径后采集当前状态，不显示、移动或恢复隐藏桌宠。建议在跨屏、修改系统缩放、休眠恢复前后分别保存一份，配合 WINDOW_STABILITY_QA.md 记录人工操作和观察。

## 内容

- 应用、Electron、Chromium 版本及是否为打包程序。
- 操作系统版本、架构、CPU 型号、内存总量。
- 显示器 ID、主屏标记、逻辑边界、工作区、DPI 缩放和旋转。
- 工坊和桌宠是否存在、可见/聚焦状态、逻辑位置与所在显示器。
- 大小/性能偏好，以及每类 Electron 进程的 CPU 和内存瞬时样本。
- 0.8.5 起，每个存活窗口附带 `rendering`，按窗口分别记录最近的绘制调用采样或不可用原因，见下文。

坐标单位为 DIP，内存进程字段为 KiB；不能把坐标直接与截图像素比较。报告不包含账号、系统用户名、保存路径、模型字节、角色名称、聊天、显示器名称或截图。没有网络上传。

JSON 标识为 `format: oigptpet-desktop-diagnostics`、`version: 1`。它是单次快照，不记录历史事件，不自动判断验收通过，也不代表 GPU 显存/功耗。用户自行选择是否分享报告。

## 绘制调用采样（0.8.5）

工坊“陪伴设置”显示**本窗口**的实际绘制调用频率、当前上限及平均绘制耗时，通常每两秒更新。桌宠有自己的独立采样，保存诊断后可在 `windows` 中按 `role: workshop|pet` 查看；工坊显示的数字不代表桌宠帧率。

`rendering.status` 可为：

| 状态 | 含义 |
| --- | --- |
| available | 收到该窗口最近的采样；`ageMs` 为收到后经过的时间。 |
| not-sampled | 暂无采样；窗口刚打开、刷新或重新显示时会清除旧记录。 |
| stale | 超过 10 秒没有新采样，`sample` 为 null，不把旧数值当作当前表现。 |
| hidden | 原生窗口当前隐藏，`sample` 为 null；不沿用隐藏前的帧率。 |

新鲜度使用主进程的单调时钟，不受用户调整系统日期影响。窗口关闭、渲染进程退出或主 frame 开始导航时清除缓存。隐藏时停止周期上报，重新显示后等待新采样。渲染进程只上报自身数据；主进程按已验证窗口归属关联记录，不接受上报内容指定另一个窗口。

绘制暂停同时参考页面隐藏状态与原生窗口 hide/show。只读可见性 IPC 仅返回调用窗口本身的状态，订阅后读取初始状态，期间如有新事件则丢弃迟到的初始值。这样在页面可见性被自动化环境或后台节流设置影响时，原生隐藏仍会停止绘制；恢复时重新采样并重置动作时间步长。[Electron 页面可见性说明](https://www.electronjs.org/docs/latest/api/browser-window#page-visibility)

`sample` 字段：

- `kind`（empty/vrm/sprite）、`mode`（quality/balanced/battery）、`activity`（active/idle/hidden）、`paused` 和 `targetFps`，说明采样时的角色类型、性能档和互动状态。
- `windowMs` 是本段实际采样时长，`frames` 是完成的 `stage.render` 调用数，`fps = frames × 1000 / windowMs`。采样短于 500 毫秒、空角色或隐藏时不生成帧率，使用 null；有效可见采样期间没有绘制则为 0。
- `meanRenderMs`、`p95RenderMs` 是调用 `stage.render` 前后的 `performance.now()` 墙钟差统计。最多保留最近 256 次耗时样本，`durationSamples` 给出实际数量；没有样本时为 null。若采样定时器被长时间延后，帧数/时长仍覆盖整段，耗时只描述最近 256 次。

性能档、闲置/互动、暂停状态或角色类型变化会重新采样，成功换角色时也会清零，即使前后都是 VRM。FPS 上限来自现有绘制策略；“暂停动画”停止动作时间推进，但仍可绘制，不等于窗口隐藏。

短采样窗的起止可能包含边界帧，显示数值可能略高于调度上限；请结合 windowMs 查看，不用单个短样本判定是否超限或达标。

这些数值衡量应用绘制调用的频率与同步耗时，**不是显示器实际呈现帧率、纯 CPU 执行时间或 GPU 完成时间**，也不测能耗、显存、丢帧率。操作系统调度、窗口遮挡、后台节流、导出或加载都可能影响数值。诊断保存的是最近采样快照，不会主动绘制隐藏桌宠、改变性能模式或发出网络请求。真实硬件 FPS 和能耗验收仍需另行记录环境及测量方法。
