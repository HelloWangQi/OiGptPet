# 桌面诊断与实机记录

在 Windows 桌面版工坊的“陪伴设置”中选择“保存桌面诊断”，选择本地 JSON 文件。网页模式不显示此入口。取消不创建文件；保存失败后可以重试。同一时间只打开一个诊断保存对话框。

报告在选择路径后采集当前状态，不显示、移动或恢复隐藏桌宠。建议在跨屏、修改系统缩放、休眠恢复前后分别保存一份，配合 WINDOW_STABILITY_QA.md 记录人工操作和观察。

## 内容

- 应用、Electron、Chromium 版本及是否为打包程序。
- 操作系统版本、架构、CPU 型号、内存总量。
- 显示器 ID、主屏标记、逻辑边界、工作区、DPI 缩放和旋转。
- 工坊和桌宠是否存在、可见/聚焦状态、逻辑位置与所在显示器。
- 大小/性能偏好，以及每类 Electron 进程的 CPU 和内存瞬时样本。

坐标单位为 DIP，内存进程字段为 KiB；不能把坐标直接与截图像素比较。报告不包含账号、系统用户名、保存路径、模型字节、角色名称、聊天、显示器名称或截图。没有网络上传。

JSON 标识为 `format: oigptpet-desktop-diagnostics`、`version: 1`。它是单次快照，不记录历史事件，不自动判断验收通过，也不代表 GPU 显存/功耗。用户自行选择是否分享报告。
