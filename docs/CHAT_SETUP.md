# 独立桌宠对话配置

适用于 0.8.3 Windows 桌面应用。局域网浏览器预览没有桌面密钥存储与对话接口；独立桌宠使用 OpenAI API，与 ChatGPT 内的聊天记录和任务状态没有同步。

1. 打开角色工坊的“对话设置”，填写 API 账户可用的模型 ID 和 API Key，再点“保存设置”。不默认指定模型，也不假定密钥必须有某个前缀。
2. 点“检查本地配置”。它只检查已保存配置的格式、系统安全存储可用性与密钥能否解密，不联网，不清空当前会话。输入框有未保存更改时，需要先保存。
3. 本地检查通过后，可手动发送一条简短消息验证网络、认证、模型访问及回复兼容性。发送会请求固定的 OpenAI Responses 端点，可能产生 API 费用；应用不会自动发送测试消息或自动重试。

保存设置会清空本次对话；密钥留空保留原密钥，“移除密钥”可移除已保存密钥。没有配置时设置区域自动展开。模型 ID 格式检查只判断语法，不证明模型存在或账户有权使用。

## 出错后的处理

| 提示 | 处理 |
| --- | --- |
| 本地密钥无法解密 | 在当前电脑和系统账户下重新填写密钥并保存，不依赖直接复制另一台电脑的配置文件。 |
| 本地检查超时 | 检查最多等待 5 秒；稍后重试，仍失败时重新保存密钥。 |
| HTTP 401 | 核对密钥是否有效，以及所属项目的访问权限。 |
| HTTP 403 | 核对项目、模型权限及服务可用地区。 |
| HTTP 404，或已知的 model_not_found | 核对模型 ID、资源及账户访问权限。 |
| HTTP 429：额度或限额不足 | 核对 API 账户可用额度及项目/组织限额，确认后再手动重试。 |
| HTTP 429：过于频繁 | 稍后手动重试。未识别出具体原因的 429 会同时提醒核对频率和额度。 |
| HTTP 400/422 | 核对模型 ID 和模型支持的请求参数；本地语法正确不代表支持当前请求。 |
| HTTP 5xx | 服务暂时异常，稍后手动重试。 |
| 连接、处理失败或请求超时 | 检查网络与配置；请求总等待上限为 60 秒，也可以取消后重试。 |

错误提示由应用生成。仅从最多 8 KiB 的特定错误响应中识别已知错误码，不展示服务返回的原始错误正文、任意错误码或账户信息。未知错误不会冒充确定的额度或频率问题。分类依据：[OpenAI API 错误说明](https://developers.openai.com/api/docs/guides/error-codes)。

## 保存和会话范围

密钥由 Electron safeStorage 在主进程加密保存；Windows 使用 DPAPI，换电脑或系统账户后如无法解密，需在本机重新保存。配置读取结果和检查结果不向页面返回密钥。具体系统行为见 [Electron safeStorage 文档](https://www.electronjs.org/docs/latest/api/safe-storage)。

会话最多保留四轮成功对话及最后一次尝试，仅在内存中保留。工坊刷新/关闭后重开可恢复会话；退出应用、清空对话或保存设置会清除会话。失败或取消的消息可手动重试；重试保留后来输入的新草稿。角色备份不包含对话设置或密钥。

## 回复朗读

工坊和独立桌宠窗口都可手动朗读最近一条完整回复，再次点击可停止。桌宠仅在完整回复到达后显示朗读按钮，生成中、失败、取消或清空时不提供旧内容朗读。朗读不会自动触发，也不会额外请求聊天 API；使用当前系统可用的语音和浏览器 `SpeechSynthesis` 实现。可用声音、语言和发音由 Windows 与所选系统语音决定。发送新消息、清空对话、保存新设置、隐藏桌宠或关闭窗口时会停止正在朗读的内容。

当 VRM 模型包含 `aa` 预设表情时，朗读会按系统语音提供的文字边界估算开合并平滑驱动口型；模型能力面板会显示是否支持。该事件是粗粒度的文字/词语位置，不含音频音量或音素，**不是真实音量同步**。缺少 `aa` 的模型和精灵图不显示朗读口型。

### 语音听写

工坊输入框和独立桌宠控制条上的“语音输入 / 听写”按钮开始或停止单次听写，临时与最终识别文字都会写入草稿；听写不会自动发送，需检查后手动点击发送。桌宠也可展开“聊聊”直接输入文字，语音和文字共用草稿。桌宠发送的消息会进入共享对话并同步到工坊历史。需要支持 Web Speech API 的运行环境和可用麦克风；不支持时语音按钮会禁用。窗口隐藏或关闭、清空对话或保存设置时会结束收音。

语音识别由系统/浏览器提供，联网方式和音频处理由相应识别服务决定。应用只接收转写文本用于编辑草稿；发送模型请求仍由用户手动确认。只有用户点击按钮后，可见的本地工坊或桌宠窗口才请求纯麦克风权限；桌宠不能读取或修改模型密钥。

桌宠收到对话失败状态时短暂播放失落动作；收到取消状态时短暂播放等待动作，并显示简短说明。详细错误仍留在工坊查看。

本项目自动化验收使用合成密钥和模拟服务。0.8.3 已验证系统原生加解密后的认证头构造，但未完成真实账户的网络、权限、额度和生成质量验收。
