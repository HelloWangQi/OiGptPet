# 阶段 01：首个桌宠原型

日期：2026-10-22。按用户要求在本阶段提交后暂停，等待协作结果与下一步安排。

## 已实现

- Electron 桌面壳：角色工坊、透明置顶桌宠、拖动手柄、空白区域鼠标穿透、托盘及恢复互动快捷键。
- 本地 VRM 1.0 导入：64 MiB 限制、拒绝外部文件/网络引用、元数据展示、本地保存及窗口间同步。
- 统一角色动作内核：九类动作和视线控制，供实时预览和导出共用。
- PNG 图集草稿导出：v1 / v2、进度、取消、整图预览、原生保存对话框。
- DeepSeek 协作接口与任务文档；工作区中的 `atlas-tools` 模块已纳入类型检查和测试，尚未接入工坊 UI。
- 协作方提供的资源候选调研保存在 `docs/RESOURCE_CANDIDATES.md`；其条款解释尚未由主开发者逐项复核，不作为直接采购、上传或再分发的依据。
- 下载官方模型的脚本，固定内容哈希并保留源地址与原始许可元数据。模型二进制、依赖、缓存和构建产物均不进入 Git。

## 验证

- `npm run build`：TypeScript 检查和 Vite 生产构建通过。
- `npm test`：3 个测试文件，30 项测试通过，包含协作模块 21 项测试。
- Electron 冒烟测试：示例角色成功加载、动作按钮切换、v2 导出、桌宠窗口创建。
- 视觉检查后修正 HTML 根节点底色；复验确认桌宠页面透明且窗口置顶。
- 实际 v2 输出：1536×2288，73 个有效格、15 个透明空格；跳跃脚底像素位置为 188 / 178 / 167 / 178 / 188，验证离地与回落。
- 冒烟测试截图和报告保存在本机 `artifacts/smoke/`，未提交到 Git。
