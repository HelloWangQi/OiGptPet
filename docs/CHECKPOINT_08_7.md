# 0.8.7 检查点：六帧动作眨眼采样

2026-11-04，继续动作视觉 QA 时发现：blink 原峰值位于 0.75 周期，宽度仅 0.055；六帧循环采样 0、1/6、2/6、3/6、4/6、5/6，全部避开闭眼区间。0.8.6 虽能正确选择左右眼通道，六帧图集仍会漏眨眼。

## 修复

待机、等待、认真工作、检查结果的闭眼峰值改为 2/3，实时和导出共用时间线；保持窄脉冲和平滑开合。四帧挥手、五帧跳跃、八帧动作保留原时机。九类动作均有闭眼采样，循环边界回到张眼；挥手仍为末帧闭眼、下一循环首帧张眼。视线格的 idle 第 0 相位保持张眼。

实际 EXE 测试增加原模型与 paired 副本 PNG 的原生保存，读取文件 SHA-256 与同次报告核对，避免查看与报告不对应的图集。性能测试中 selectOption 不会像用户交互那样产生 pointer/key 事件，现切换画质后明确互动再等待 active 帧率，避免较慢运行跨过闲置门槛后误等；没有为此改变产品性能策略。
