## D5：补齐局域网 HTTP 下的 SHA-256，必须先做

当前 `packages/atlas-preview/index.ts` 的 `digestSha256` 在 `crypto.subtle` 不存在时直接抛错；而本项目已经要求支持局域网 HTTP。请修复这个明确的兼容缺口。

可修改：

```text
packages/atlas-preview/**
tests/atlas-preview.test.ts
tests/fixtures/atlas-preview/**
scripts/atlas-preview-smoke.mjs
docs/ATLAS_PREVIEW.md
```

要求：

1. 可用时优先使用 Web Crypto；不可用时回退到浏览器内可运行的 SHA-256 实现，不依赖 Node、不添加运行时依赖、不调用网络摘要服务。
2. 两条路径都返回精确文件的标准 SHA-256、小写 64 位十六进制；不允许空值、临时标识、文件名哈希或用其他算法替代。
3. 公开的 `createAtlasPreview / load / dispose` 接口保持不变；加载仍返回调用者传入的同一个 Blob。
4. 测试覆盖标准向量（空字节、`abc`、跨 64 字节块的数据）、二进制零字节、真实 PNG/WebP 字节。Node crypto 只允许作为测试中的对照实现，不进入浏览器模块。
5. 必须覆盖 `crypto.subtle` 缺失、原生路径可用、纯 JS 回退路径，以及取消/过期任务不写回 UI。20 MiB 上限内的文件不能长期阻塞 UI；必要时分批处理并在批次间检查取消。
6. 扩展独立 smoke，模拟无 subtle 的环境，并尽可能用实际非 localhost 的 HTTP 地址验证；记录真实 `isSecureContext`、subtle 是否可用、访问地址及哈希一致性，未执行的场景标注未执行。不要把 localhost 的成功当作局域网 HTTP 的证据。
7. 使用独立随机端口，不重启、占用或终止主工坊的 5173 服务，不修改主项目 Vite 配置。清理自己创建的临时目录前核对解析后的绝对路径属于预期临时父目录和任务前缀，不跨 shell 拼接删除命令。
8. 更新文档说明两条摘要路径、性能及测试结果；主程序无需根据环境另写一套哈希实现。

验收：原生与回退摘要逐字节一致；无 subtle 时实际图集可以检查和预览；取消与资源释放回归通过。
