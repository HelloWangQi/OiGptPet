## 1. AvatarSample_A / B / C

- **作者 / 权利方**：pixiv 株式会社（VRoid Project）。
- **原始发布页**：
  - 官方利用条件：[AvatarSample A〜Z - VRoid ヘルプ](https://vroid.pixiv.help/hc/ja/articles/4402394424089-AvatarSample-A-Z)（最终更新 2024/12/26）
  - AvatarSample_A：[VRoid Hub 模型页](https://hub.vroid.com/en/characters/2843975675147313744/models/5644550979324015604)
  - AvatarSample_B：[VRoid Hub 模型页](https://hub.vroid.com/en/characters/7939147878897061040/models/2292219474373673889)
  - AvatarSample_C：[VRoid Hub 模型页](https://hub.vroid.com/en/characters/1248981995540129234/models/8640547963669442173)
- **提供格式**：`.vroid`（VRoid Studio 内选择、下载）与导出的 VRM；VRoid Hub 的 A 模型页标注格式为 `VRM 0.0`。
- **模型版本**：A 已确认为 VRM 0.0；B/C 的模型页未逐一核查版本。
- **个人桌宠使用**：官方条件允许“VRM 対応の各種アプリケーションで、アバターや登場キャラクターとして利用する”。可用于独立桌宠。
- **渲染 / 精灵图导出**：允许“サンプルモデルを撮影した動画や画像を使って作品を作る”，并允许编辑纹理、参数后制作原创角色。导出精灵图属于图像作品制作。
- **上传第三方平台**：官方条件未按平台限制，允许广泛利用；但上传源 VRM 仍需遵守目标平台条款。VRoid Hub 模型页的 Redistribution 标注为 Allow。
- **源模型再分发**：VRoid Hub 模型页标注 `Redistribution: Allow`。官方帮助页同时禁止“正当な理由なく有償で再配布する行為”，并禁止把 VRM 许可证的再分发/改変范围设为 CC0。免费再分发需保留原条件，不能当作 CC0。
- **渲染产物再分发**：允许，包含商业用途。
- **署名**：明确“クレジット表記は不要です”。
- **关键原文**：
  - 「本サンプルモデルの.vroidファイルおよび出力したVRMファイルは、どなたでも、無料で、営利・非営利を問わず、商業活動を含むさまざまな用途で利用できます。」
  - 「本サンプルモデルの利用にあたり、クレジット表記は不要です。」
  - 禁止「サンプルモデルの.vroidファイルまたはVRMファイル、およびこれらに含まれる画像等のデータを正当な理由なく有償で再配布する行為」。
  - 禁止「VRMライセンスの『再配布・改変に関する許諾範囲』を『著作権放棄(CC0)』に設定する行為」。
- **VRoid Hub 模型页标注的条件**：Avatar Use: Allow / Corporate use: Allow / Individual commercial use: Allow / Redistribution: Allow / Alterations: Allow / Attribution: Not required。
- **未确认项**：
  - B/C 的 Hub 条件与模型版本未逐一核实。
  - “正当な理由”的具体边界未定义；涉及有偿再分发源模型时应单独确认。
  - 下载 VRM 需要 VRoid Hub 账号并同意其利用条款；本次未注册、未下载。
  - 目标平台对精灵图的实际接受规则不由本许可决定。

## 2. アリシア・ソリッド（Alicia Solid / ニコニ立体ちゃん）

- **作者 / 权利方**：企划 株式会社ドワンゴ；角色设计 黒星紅白；模型制作 雨刻。
- **原始发布页**：
  - [ニコニ立体ちゃん特設サイト](https://3d.nicovideo.jp/alicia/)
  - [VRM 模型配布页](https://3d.nicovideo.jp/works/td32797)
  - [ニコニ立体ちゃんライセンス利用規約](https://3d.nicovideo.jp/alicia/rule.html)
- **提供格式 / 版本**：`Alicia_VRM.zip`（5.26 MB，2019/05/17 更新，版本 1）；另有 FBX、MMD、Unity Package。页面未标注 VRM 版本；按发布时间推测为 VRM 0.x，但未核实。
- **个人桌宠使用**：利用者定义为“个人（法人を除く団体を含む）”。许可允许制作二次创作品，以及在桌宠中复制、展示（上映/展示）该角色。个人使用可以。
- **渲染 / 精灵图导出**：许可允许制作二次创作品，并允许复制、上演、上映、公衆送信、展示、販売・頒布用户自己制作的二次创作品。导出精灵图并播放/发布属于该范围。
- **上传第三方平台**：允许对自己制作的二次创作品进行公衆送信和頒布；但源 VRM 的再分发范围需另行确认（见下）。
- **源模型再分发**：作品页元数据标注 `再配布: 可能`；但许可正文主要授权“二次创作品的制作与利用”，没有逐字列出“原模型数据再分发”条款，同时禁止将许可权利再授权给第三方。建议把“原文数据随软件分发”视为待确认项，不要仅凭元数据发布。
- **渲染产物再分发**：允许（用户自作的二次创作品），可用于商业目的，但须遵守不得损害名誉、不得误认为官方产品等条件。
- **署名**：特别站点与作品页均标注“表記不要 / 著作表示 不要”。
- **关键条件**：
  - 「無料・表記不要・改変可」「商用利用可 (法人を除く)」。
  - 许可第 3 条允许「当社キャラクターの二次創作物を作成すること」及「利用者自ら作成した当社キャラクターの二次創作物を複製、上演、上映、公衆送信、展示その他販売・頒布すること」。
  - 第 3 条第 3 项：「利用者は、当社が本ライセンスで許諾した権利を第三者に再許諾することはできないものとします。」
- **未确认项**：
  - 源模型原文再分发的完整范围；作品页“再配布可能”与许可正文的关系。
  - VRM 版本。
  - 下载需要ニコニコ账号并登录；本次未注册、未下载。
  - 若发布主体为法人，不能使用本许可；需单独取得授权。
  - 目标平台条款及平台对角色内容的上传限制。

## 3. シードさん（Seed-san）

- **作者 / 权利方**：株式会社バーチャルキャスト。
- **原始发布页 / 许可**：[シードさんVRM配布 - VirtualCast Wiki](https://wiki.virtualcast.jp/wiki/vrm/seedsanvrm)（最终更新 2023/08/28；页面为官方 VirtualCast Wiki，含完整许可与下载链接）。
- **提供格式 / 版本**：`seed_san.zip` 内的 VRM 数据。页面未标注 VRM 版本，未核实。
- **个人桌宠使用**：明确“個人利用、法人利用問わずご利用できます”，可免费用于桌宠等作品。
- **渲染 / 精灵图导出**：允许“このデータを用いて作った作品の営利目的での使用（販売）”，并允许对数据进行改変、追加。导出精灵图属于使用该数据制作作品。
- **上传第三方平台**：许可允许复制、公衆送信、展示、販売・頒布；渲染产物可上传。未改変的源 VRM 数据不得再分发。
- **源模型再分发**：允许再分发“自身で改変したデータ”；禁止“未改変データの再配布”。FAQ 明确“ゲームに入れる、グッズに印刷する”等加工也属于改変，即使外观未变。因此在应用内打包 VRM 可能被视为改変后使用，但直接分发与官方文件完全相同的原始数据仍然禁止。
- **渲染产物再分发**：允许，商业用途也可。
- **署名**：没有明确的署名义务；禁止“未改変データの作者と偽ること”，不得冒充 VirtualCast 官方。
- **关键条件**：
  - 「個人利用、法人利用問わずご利用できます。」
  - 「このデータを用いて作った作品の営利目的での使用（販売）が可能です。」
  - 「自身で改変したデータの再配布が可能です。」
  - 禁止：「未改変データの再配布」「未改変データの作者と偽ること」。
  - FAQ：「ゲームに入れる、グッズに印刷するなど見た目は変わっていなくても何かしらの加工を行っているものを『改変』と称しています。」
- **未确认项**：
  - VRM 版本。
  - “改変”在具体打包/转换场景下的边界（FAQ 举例支持，但未逐项确认）。
  - 目标平台条款及平台内容审核。

## 使用建议与待决问题

1. **当前推荐的验证角色**：AvatarSample_A 或 Seed-san。前者有 VRoid 官方完整许可与明确 VRM 0.0 版本；后者对个人/法人、商业用途和改変都更宽松，但禁止再分发未改変数据。
2. **Alicia Solid** 仅适合个人或非法人团体发布；若项目以后由公司运营，不能沿用该许可。
3. **默认分发策略**：仓库和安装包不附带源 VRM，只提供本地导入与渲染产物（精灵图、预览图）。这样可以把许可问题集中在“渲染产物”而非“源模型再分发”。
4. **发布前必须复核**：各页面条款可能变更；应重新读取原始页面并记录日期与链接。精灵图上传到目标平台前，还需核对目标平台自身的条款，不能以本文件替代。
5. **未做的事**：未向作者询问、未购买、未注册账号、未下载模型、未上传任何角色或产物。
