## 方法与产物

`scripts/atlas-visual-qa.mjs` 在临时 Electron 窗口中解码实际编码图集，读取 RGBA 后只做整数倍放大、排版和像素统计；不重绘、不修补、不重新居中、不裁掉单格。所有联系表保留完整 192×208 格：

| 产物 | 内容 |
| --- | --- |
| `state-<state>.png`（9 张） | 九种状态的完整帧序列，2×；每格标注帧号、alpha 底边和与上一帧的差异像素数 |
| `jump-baseline.png` | 跳跃五帧 3×，红色虚线标出五帧最低底边 188px |
| `idle-heads.png` | 待机六帧头部 80×96 区域 6× |
| `idle-reference.png` | 中性待机第 0 行第 0 帧：完整格 3×、头部 6×，明确标注“不作视线正确性证据”；该帧本身带有下面记录的头发发刺，只作姿势/朝向参考，不是无缺陷基线 |
| `gaze-directions.png` | 16 方向完整格 2×，按 4×4 排列并标注角度/屏幕方向 |
| `gaze-heads.png` | 16 方向头部 80×96 区域 6× |
| `gaze-eyes.png` | 16 方向眼部 36×20 区域 20×，标注眼区差异像素与差异框 |
| `manifest.json` | 输入哈希/尺寸、结构检查、逐帧 alpha 边界、帧间差异、状态对比、视线统计与复跑命令 |

统计口径：

- 逐帧 alpha 边界给出 `bottom / centerX / width / height`；空帧为 `null`。
- 帧间/状态间差异为完整单格中至少一个 RGBA 通道相差 **>8** 的像素数；单格共 39,936 像素。
- 状态对比取每个状态中间帧；视线对比以第 9 行第 0 帧（0° 上）为基准。
- 视线另算头部 80×96、眼部 36×20 的差异；下方身体区域 `y=96..207` 的差异用于判断有没有整个人转身。
- 结论分级：`pass` 可接受；`warning` 有明显局限但不构成失败；`fail` 有具体可见缺陷；`not-reviewed` 未目视或未执行。只有实际查看图片后才给 pass/warning/fail。

关键证据：

- **不是整身转身**：16 个方向相对 0° 的下方身体区域（y=96–207）差异为 0 或 1px；差异集中在头部和眼部。
- **不是静止重复帧**：没有与 0° 完全相同的头部帧；每对相邻方向眼区差异 203–245px，16 帧不是同一张图复制。
- **四个正方向**：0°、90°、180°、270° 的眼区差异分别为 0、308、332、319px；20× 眼部特写中瞳孔分别位于上、右、下、左，四个方向成立。
- **中间方向**：22.5° 步进的变化在原生 192×208 尺寸下较难单独辨认，但在 20× 眼部特写中瞳孔位置按上→右上→右→右下→下→左下→左→左上连续变化。因此记为 `pass`，同时保留“原生尺寸下档位较细”的限制。
