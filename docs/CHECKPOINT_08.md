# 0.8.0 本地检查点：内存会话恢复

基线 5d25ae1。用户要求继续下一步，本轮补充窗口生命周期中的对话恢复，不持久化聊天、不执行真实付费请求、不推送或发布。

## 交付

- 工坊刷新/关闭只取消当前未完成请求，成功历史仍在主进程内存保留最多四轮。重新打开后恢复历史及最后一次取消/失败的原消息、片段和重试入口；未发送草稿不保留。
- 在流式中途打开或刷新桌宠，会在角色加载后重放当前回复状态；回复完成后原地更新气泡。
- 会话快照是脱离内部引用的副本，内容仅含有界成功历史、最后一次尝试和显示状态。工坊主 frame 可读完整快照，桌宠仅可读显示状态，不返回配置密钥。
- 主进程事件和快照带递增序号，渲染器忽略旧事件；迟到快照不会覆盖已收到的新状态。恢复本身不触发网络请求。
- 清空对话、保存设置和退出应用仍会清除本次会话，应用重启只恢复模型/密钥配置。诊断和角色备份不包含聊天。
- 收紧 IPC 归属检查：没有所属窗口、销毁窗口、无关窗口、子 frame 均拒绝；不会因工坊槽位为 null 而允许无归属发送者。关闭窗口时的通知异常不会阻止向另一窗口发送状态。

产品界面已说明内存会话保留与未发送草稿的边界。没有增加永久聊天文件或后台重试。
