# OiGptPet 0.3.0 · 多角色与精灵图桌宠

- 本地角色库支持 VRM 1.0 和 v1/v2 PNG/WebP 图集，最多 12 个角色、原始文件合计 256 MiB；支持改名、切换和移除非当前角色。
- 独立桌宠可播放精灵图动作及 v2 十六方向视线；按 alpha 命中透明区域，支持缩放和像素倍率变化。
- 切换时先加载候选角色，再保存选择并替换画面；加载、取消或存储失败保留原角色。切换释放旧 VRM/WebGL 或 Bitmap，阻止过期结果恢复画面。
- 工坊与桌宠同步选择，重启恢复角色和名称；从旧 Electron 模型文件或浏览器旧数据库迁移，保留旧数据。
- 新增小/标准/大三档桌宠大小，以及画质/均衡/省电模式。绘制上限 60/30/15 fps，闲置降为 30/12/5 fps，隐藏时停止绘制；设置本机保存并在窗口间同步。
- 保留 VRM 图集导出和检查报告。精灵图直接播放原动作，导出新的动作图集需要源 VRM。

下载 `OiGptPet-v0.3.0-win32-x64.zip`，完整解压后运行 `OiGptPet.exe`。Windows x64 免安装目录包，Electron 45.0.0。默认不附带模型、用户数据或导出图集；导入 VRM ≤64 MiB，或符合本项目规格的 PNG/WebP ≤20 MiB，普通立绘不能直接当作动画图集。

本阶段验证涵盖单元测试、真实 IndexedDB、桌面迁移、VRM/精灵图反复切换、失败回退、取消、窗口同步、重启恢复及生产包启动。具体证据和未测项见仓库 `docs/CHECKPOINT_03.md`。
