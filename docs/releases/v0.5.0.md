# OiGptPet 0.5.0 Preview · 桌宠稳定性与交互

## 更新

- 工坊“陪伴设置”新增本地桌面诊断 JSON，记录显示器、窗口与性能快照，支持多屏/DPI/休眠的人工排查。侧栏版本号与应用版本一致。

- 修正鼠标跟随时头部与眼睛左右方向相反的问题。
- 可以直接按住可见角色身体拖动桌宠；轻点仍触发动作，底部按钮和透明区域不会误作拖动把手。
- 显示器变化与系统恢复时重新定位桌宠；普通退出前原子保存最近位置。
- 安装后默认不附带模型。角色备份、原始模型和测试图集不包含在发布包中。
- 一小时软件稳定性运行通过：3600.51 秒、39 次角色切换、9 轮拖动/隐藏交互检查、119 个采样，未记录应用错误。

## 预览版限制

- 一小时运行使用 SwiftShader 软件渲染。真实显卡、能耗、多屏、负坐标、100%/150%/200% DPI、显示器拔插及休眠恢复还没有在目标硬件完整验收。
- ChatGPT 官方入口的登录、模型上传/安装和宿主内动画观察尚未完成；本版本只验证导出与本地功能。
- GPU 进程内存按 VRM / 精灵图分类型观察到约 49 MiB / 66 MiB 的首末净增（每类约 53–55 个样本）；均未达到项目 100 MiB 复核线，但保持正斜率，后续版本继续跟踪。这不是对泄漏的诊断。
- 本次发布包不包含 VRM 模型或测试数据；只分发应用运行文件。
