## 外部动作轨道匹配提示

导入 `.vrma` 后，工坊会对照当前 VRM 检查动作片段里的：

- 规范化人形骨骼旋转轨道及 hips 平移轨道。
- 预设和自定义表情轨道。
- 动作是否含视线轨道，以及角色是否加载视线控制器。

摘要在导入和切换片段时更新。未匹配的轨道会标出，提示它们可能不会播放；仍允许预览已解析片段。

检查只比较当前模型的轨道目标，不评价动作语义、角色比例、衣物碰撞或实际视觉效果。VRMA 仍只在工坊临时预览，不保存进角色包或图集，也不作用于精灵图桌宠。

实现提交：`bf23132`。验证时需从当前源码运行 `npm run verify:desktop`，不要复用 0.9.2 的 EXE。
