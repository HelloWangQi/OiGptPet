# OiGptPet 0.4.0 · 角色备份与恢复

- 新增单角色 `.oipet` 备份，保留原始 VRM/PNG/WebP 字节、名称及 v1/v2 图集规格。
- 可以在干净的应用数据目录或浏览器中恢复角色；重复恢复复用原身份，保留库内已有名称。
- 容器版本、长度、类型和摘要校验后，再走现有模型/图集加载与角色库验证；无效文件保留当前角色。
- 桌面保存通过临时文件和最终重命名落盘，复核完整文件哈希，处理写入失败、取消和窗口关闭。开始最终重命名后不将已提交的写入报告为已撤销。
- 备份/恢复与角色切换、窗口同步和动画导出按操作状态协调，阻止迟到结果替换新状态。
- 增加跨 profile 恢复、20 次切换、资源计数和内存样本验证；发布工具要求显式版本，并用 GitHub API 校验远端提交。

Windows x64 目录包，完整解压后运行 `OiGptPet.exe`。默认不附带模型、用户备份或测试数据；备份在用户选择的本地位置保存。VRM ≤64 MiB，图集 ≤20 MiB；备份只含一个角色，不迁移应用设置或整个角色库。

ChatGPT 官方预检/安装、完整一小时稳定性、多屏/DPI/休眠和实测能耗尚未完成；短时资源探针不等于长期无泄漏。具体测试记录与交付状态见 `docs/CHECKPOINT_04.md`，本文件是版本说明，生成它不代表已创建 GitHub Release。
