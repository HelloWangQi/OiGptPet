# OiGptPet 0.6.0 Preview · 文本对话陪伴

- 工坊新增文本对话：配置 OpenAI 模型 ID / API Key 后发送消息，保留最近四轮会话上下文。
- 桌宠显示回复气泡，思考时切换工作动作，收到回复后挥手；隐藏的桌宠保持隐藏。
- 支持取消、清空对话、60 秒超时和服务失败提示；清空后迟到回复不会覆盖新会话。
- API Key 由系统安全存储加密；空白保留、显式移除，系统加密不可用时拒绝保存新密钥。
- 包含上一阶段的身体拖动、鼠标左右跟随修复、窗口恢复、原子位置持久化和本地诊断导出。

Windows x64 目录包，解压完整目录后运行 OiGptPet.exe。无内置模型、密钥、用户数据或测试资产。API 请求只在用户点击发送后发生，费用由用户配置的 API 账户承担。

本轮测试使用模拟服务和合成密钥，不调用付费 API；真实账户线上响应、真实硬件多屏/DPI/休眠和 ChatGPT 官方宠物安装尚未验收。此前的一小时稳定性结果发生在对话和诊断功能加入前，不能作为新增对话功能满小时验收。由于这些限制，本版本标记为预发布。

详情见 docs/PHASE_06.md。

验证：22 个单元测试文件、266 项通过；生产构建与实际 Windows EXE smoke 通过，覆盖模拟回复、系统密钥加密、取消/清空、IPC 权限、纯文本输出和重启配置，同时复验角色库、诊断和身体拖动。最新构建位置以 release/latest.json 为准。
