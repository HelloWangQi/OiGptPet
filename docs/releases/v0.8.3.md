# OiGptPet 0.8.3 Preview · 对话配置检查与认证修复

本地阶段版本，尚未推送或发布到 GitHub。

- 修正 Electron 异步解密返回值的读取：使用对象中的 result 作为密钥，避免把整个对象写入 Bearer 认证头。已有加密配置格式不变，无需迁移。
- 首次未配置时自动展开设置，增加填写、保存、本地检查与手动发送的步骤说明。保存前检查模型 ID 和密钥字符格式。
- 新增不联网的“本地检查”，检查已保存配置和本机密钥解密；不清空会话，最多等待 5 秒，操作期间防止并发保存或发送。
- 区分认证、访问权限、模型、请求频率、额度/限额和服务异常提示。未知 429 保留原因不确定性，不自动重试，不显示原始错误正文。

362 项单元测试、编译打包及实际 EXE 冒烟检查通过。实际 EXE 测试使用系统原生安全存储及合成密钥，严格核对模拟请求的认证头，并确认保存/本地检查不发请求。

真实 API 账户对话尚未验收；模型访问、网络、额度与生成质量仍需实际环境验证。0.8.2 的满小时结果仅属于当时的版本和模拟负载，不能替代本版真实 API 或满小时验收。物理多屏/DPI/休眠、更多模型动作视觉检查及 ChatGPT 官方宠物安装仍待完成。
