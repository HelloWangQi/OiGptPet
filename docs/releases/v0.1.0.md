# OiGptPet 0.1.0 · 桌宠原型

首个 Windows 桌宠版本，源代码对应提交 `7ea0cbc70f19a835610b80e8bbf714626d76fef9`。

- 角色工坊与本地 VRM 1.0 导入，支持九种动作和鼠标视线互动。
- 透明置顶桌宠窗口、拖动、鼠标穿透、托盘、快捷键恢复互动及窗口位置保存。
- 将源 VRM 导出为 v1/v2 透明 PNG 动画图集，包含本地结构检查。
- 保存当前模型，重启后恢复。

下载 `OiGptPet-v0.1.0-win32-x64.zip`，完整解压后运行 `OiGptPet.exe`。支持 Windows x64；本次从历史提交重建，使用 Electron 45.0.0。构建时排除 public 模型，包内不附带源 VRM、用户角色或导出图集，首次使用请导入自己的 VRM 1.0。

这是历史原型版本。后续 0.2.0 增加最终文件逐帧预览、检查报告和导出动画修复；0.3.0 增加角色库、精灵图桌宠及设置持久化。ChatGPT 官方预检与安装未完成，导出文件需在目标入口另行验收。

发布附件提供 SHA-256 校验文件；ZIP 为免安装目录包，不是安装向导。模型和渲染产物的许可请分别核对作者说明。
