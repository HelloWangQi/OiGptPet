# OiGptPet 0.2.0 · 导出检查与动画修复

源代码对应阶段二最终提交 `402bbf8`，包含该阶段后续集成与修复。

- 工坊支持局域网浏览器访问，Electron 继续使用本机连接；角色保存在使用设备上。
- 从实际编码 PNG 检查尺寸、帧占用、透明格和体积，提供逐帧播放、暂停、单步及 v2 十六方向视线预览。
- 检查报告记录模型来源、精确 SHA-256、字节数及本地/平台验收状态；结构失败时禁用 PNG 保存。
- 桌面保存再次校验文件哈希；关闭弹窗、换模型和取消导出清理过期结果与资源。
- 修复导出首帧物理初始化，调整失落、工作等姿态，保留可复现的图集与视觉 QA 记录。
- 默认生产构建和 Windows 包排除模型与本地资产，并增加实际发布包启动检查。

下载 `OiGptPet-v0.2.0-win32-x64.zip`，完整解压后运行 `OiGptPet.exe`。Windows x64 免安装目录包，Electron 45.0.0；首次启动导入自己的 VRM 1.0。包内不附带源模型、用户数据或导出图集。

该版本已经验证 VRM 导入、v1/v2 导出与逐帧检查；角色库、精灵图桌宠和性能设置从 0.3.0 开始提供。ChatGPT 官方预检与安装仍未完成，本地通过不代表目标平台接受。

发布附件提供 SHA-256 校验文件。模型和渲染产物的许可请分别核对作者说明。
