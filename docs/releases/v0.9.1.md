# OiGptPet 0.9.1 动作重播衔接

重复点击当前动作会将动画时间轴重置到开头。VRM 实时预览和桌宠现在会识别显式重播，即使动作名称未变，也从当前画面中的骨骼、表情、视线和角色根节点状态平滑衔接。精灵图桌宠的动作切换、重播，以及 v2 视线模式进入/退出均使用 200 ms 淡入淡出；过渡被快速打断时，会从屏幕上当下显示的画面继续；视线方向变化仍即时响应。

精灵图文件与图集导出采样不变。工坊新增手动系统语音朗读最近一条完整回复；它不自动播放、不额外请求 API。35 个测试文件、415 项单测通过。真实 EXE 冒烟报告：`artifacts/release-smoke/run-1793841484208/result.json`；动作混合、暂停恢复、聊天回归通过，渲染错误为 0。自动化没有实际播放系统语音；目标机器的语音可用性和口音仍需人工体验。SwiftShader 冒烟不能替代目标显卡性能或用户设备长时间体验。
