# OiGptPet 0.8.7 Preview · 修复六帧动作导出漏眨眼

本地开发版本，未推送或发布。

- 修正待机、等待、认真工作和检查结果四类六帧动作的眨眼时机：原来的闭眼峰值在 3/4 周期，六帧导出没有采到它；现在落在 2/3 周期，使导出帧包含闭眼。
- 实时渲染与图集导出继续使用同一动作时间线；保持原有窄脉冲的平滑开合，不改变四帧/五帧/八帧动作的眨眼时机。
- 实际 EXE 检查保存原模型和左右眼适配副本的 PNG，并核对文件摘要与导出报告一致，便于查看眼部细节。

33 个文件、402 项单元测试通过，覆盖九类动作的闭眼采样及循环回到张眼。具体模型的眼睑绑定和视觉效果仍需预览；通道不可用时继续按已有规则降级，不合成缺失的表情。

当前源码已完成编译打包和实际 EXE 验收；已查看该测试角色及左右眼副本的待机 PNG，闭眼格和后续张眼格可辨认。范围与产物见 [检查点](../CHECKPOINT_08_7.md)，不将局部检查当作整套动作视觉验收。
