# OiGptPet 0.8.2 · 释放 VRM 解码位图

- 修复 VRM 替换或释放时只清理纹理对象、未关闭其解码 ImageBitmap 的遗漏；同一模型内共享图片只关闭一次，正常释放、取消后完成加载和缺失 VRM 候选的路径共用清理。
- 增加实际 EXE 的位图关闭计数检查，保留对话、角色切换、隐藏恢复和窗口生命周期回归。
- 新增固定窗口的内存定位模式，区分工坊/桌宠原生 PID，分别记录切换后立即采样和等待回收后的数据。原始内存提示继续保留，不强制 GC 或修改增长阈值。

此版本目前为本地检查点，未发布 GitHub Release。角色和密钥由用户自行配置，发布包不附带模型或用户数据；模拟服务检查不执行真实付费请求。

显式资源释放修复不代表此前所有内存增长均已解决，仍需预热后的满小时混合负载与真实设备验收。

验证：317 项单元测试、重新编译后的实际 EXE 基础验收、四轮混合生命周期及八轮固定窗口检查通过。固定窗口每个窗口的 144 张 VRM 解码位图均对应关闭；该短测未触发原始或等待后内存提示，不构成长测结论。
