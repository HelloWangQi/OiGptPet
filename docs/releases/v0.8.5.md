# OiGptPet 0.8.5 Preview · 工坊独立滚动与绘制监测

本地阶段版本，尚未推送或发布到 GitHub。

- 桌面工坊固定在窗口高度内，右侧设置独立滚动，滚到下方时左侧角色预览和动作区保持原位。滚动到底不会带动整页；窄屏单列网页保留页面滚动。

- 工坊“陪伴设置”新增本窗口的绘制帧率、当前帧率上限与平均绘制耗时，通常每两秒更新。
- 桌面诊断分别记录工坊和桌宠的采样，包含互动/闲置状态、性能档、采样时长及平均/P95 调用耗时，便于对比设置和复现问题。
- 换角色、换性能档、进入闲置或隐藏时重新采样。窗口刷新、关闭或重新显示后不沿用旧缓存；未采样、过期及隐藏各有明确状态。隐藏时停止周期上报。
- 隐藏暂停同时参考原生窗口可见性，避免只依赖页面状态；隐藏时停止绘制，恢复后重新开始采样。

保留 0.8.4 的动作适配报告及 0.8.3 的聊天认证修复。监测不改变现有绘制频率策略，不上传数据，也不自动判断性能达标。采样是绘制调用的频率和同步耗时，不代表屏幕呈现帧率、GPU 完成时间或实际能耗；详情见 [桌面诊断](../DESKTOP_DIAGNOSTICS.md)。

验证：32 个测试文件、385 项通过；当前源码的编译、打包和实际 EXE 冒烟全部通过。实际检查覆盖三种工坊尺寸、右栏滚动、互动/闲置帧率采样、原生隐藏停止绘制和恢复新采样，以及既有角色、对话和导出回归。详见 [阶段检查点](../CHECKPOINT_08_5.md)。

真实 API、物理多屏/DPI/休眠、更多模型连续动作视觉 QA 及 ChatGPT 官方宠物安装仍待实际环境验收。
