# OiGptPet 0.8.0 Preview · 流式对话与会话恢复

本版本包含 0.6.0 以来的对话改进：

- 工坊和桌宠逐步显示生成中的文字，完成后更新同一条回复。
- 流意外中断或取消时标记未完成片段，恢复原消息并支持重试；片段不进入后续上下文。
- 失败重试保留后来输入的新草稿；支持 Ctrl/⌘+Enter 发送并避免输入法组合键误触。
- 工坊刷新或关闭后，重新打开可恢复本次最多四轮成功对话及最后一次失败/取消消息。关闭工坊会取消未完成请求；未发送草稿不保留。
- 在流式回复中途新建或刷新桌宠，可恢复当前气泡状态。退出应用、清空对话或保存设置会清除会话；没有聊天磁盘文件。
- 请求取消覆盖解密、连接与响应读取；修正密钥删除和设置保存边界，收紧 IPC 窗口归属检查。

Windows x64 完整解压后运行 OiGptPet.exe。在工坊配置账户可用的 OpenAI 模型 ID 与 API Key；只有点击发送才请求服务，费用由配置的 API 账户承担。包内不附带模型、密钥、用户配置或测试数据。

验证：24 个单元测试文件、305 项通过；实际 EXE 验证覆盖流式回复、中断重试、工坊重开、桌宠状态重放、配置加密、快照权限、清空及重启，并复验角色库、诊断与身体拖动。

本轮使用合成密钥和模拟服务；真实 API 账户、多屏/DPI/休眠、硬件能耗及 ChatGPT 官方宠物安装尚未验收。旧的一小时稳定性记录早于对话功能，不能作为本版满小时验收。保留预发布标记，详情见 docs/CHECKPOINT_08.md。
