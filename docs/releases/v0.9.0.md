# OiGptPet 0.9.0 VRM 动作过渡

VRM 实时预览和独立桌宠在切换动作状态时，新增 200 ms 平滑过渡。过渡同时覆盖归一化骨骼、表情、视线目标和角色根节点位置/朝向；过渡时长随实际帧时间推进，并使用平滑曲线收尾。连续切换动作时，从当前画面继续过渡。

精灵图播放与动画图集导出不变，图集导出仍按指定状态和时间点直接采样。

验证结果：34 个测试文件、408 项单测通过；`npm run verify:desktop` 的 Windows 打包及实际 EXE 冒烟检查通过。验证包位于 `release/v0.9.0-1793762152485/OiGptPet-win32-x64/OiGptPet.exe`，对应源码提交 `d3b637d`。连续动作过渡尚未做人工视觉验收。发布 ZIP 和 SHA-256 校验文件见 GitHub [v0.9.0 Release](https://github.com/HelloWangQi/OiGptPet/releases/tag/v0.9.0)。
