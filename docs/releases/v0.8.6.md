# OiGptPet 0.8.6 Preview · 左右眼眨眼适配

本地开发版本，尚未推送或发布。

- VRM 缺少通用眨眼表情时，自动使用齐全的左右眼独立表情同步眨眼；实时桌宠与动画导出共用此适配。
- 同时提供通用和独立眼睛表情时优先使用通用表情，清除未使用通道，避免权重叠加；只提供一侧时不自动制造单眼眨眼。
- 动作适配面板显示实际选择方式，导出报告增加 blinkMode，区分通用、双侧和不可用。原有预设存在记录保持原意，旧报告可继续解读。

33 个文件、392 项单元测试通过，覆盖闭眼/张眼清零、优先级、单侧降级、模型隔离和报告兼容。用户开会期间已暂停 EXE 验收，本版尚不可作为已验收发布包。恢复后需检查原模型、双侧表情副本、无眨眼副本及既有桌面回归；具体眼睑视觉效果仍需按模型预览确认。
