# OiGptPet 0.9.2 本地阶段说明

> 此版本为本地检查点，尚未推送或发布为 GitHub Release。

## 新增

- 工坊可从本地导入 `.vrma`，在当前加载的 VRM 上预览动作片段。
- 支持选择片段、暂停/继续以及清除动作并恢复内置动作。
- VRMA 仅限当前工坊预览，不写入角色库或备份包，也不包含在精灵图导出中。

## 修复

- 本地回复已完成后，迟到的同请求状态事件不再重新水合历史并覆盖完成提示。
- 对话历史同步期间开始新的本地请求时，过期快照不会覆盖当前会话。

## 验收

- `npm run verify:desktop`：通过，包含源码编译、Windows 打包及发布包冒烟。
- 发布包冒烟结果：`artifacts/release-smoke/run-1793868495078/result.json`。
- 冒烟使用运行时合成 VRMA，检查导入播放、暂停/继续、无效替换保留已有动作、清除后恢复内置动作及聊天迟到事件回归；未访问真实 API。
- 本轮 EXE：`release/v0.9.2-1793868490891/OiGptPet-win32-x64/OiGptPet.exe`，源码提交 `bba86ac`。

## 待人工验收
