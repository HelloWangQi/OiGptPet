# OiGptPet 0.10.0 开发检查点

> 开发中。基于本地提交 `1937725`；本轮代码尚未编译、测试或打包，请勿用已有 EXE 验收这些改动。未推送或发布。

## 本轮范围

- 同一份 VRMA 可将不同片段分配给多行动作行；每行可更新或移除分配。
- 未加入清单的动作行继续使用内置动作。旧的单行动作行选择流程继续兼容。
- 导出报告保留单行时的 `externalAnimation` 字段，多行时使用 `externalAnimations` 数组；不记录本机路径。
- 更换/清除 VRMA 时清空临时分配；动作文件仍只保存在当前工坊会话。

## 尚待完成
