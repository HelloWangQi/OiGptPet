# OiGptPet 0.10.0

GitHub 正式 Release 已发布：[OiGptPet v0.10.0](https://github.com/HelloWangQi/OiGptPet/releases/tag/v0.10.0)。源码提交 `aa398836da33a71de2f4ab55ffcdafecaf4064b3`。

## 更新内容

- 工坊支持把同一份 VRMA 文件中的不同片段分别分配给多行动作行。
- 可更新或移除行分配；未分配的行保留内置动作。
- 单行动作报告继续使用 `externalAnimation`；多行动作报告使用 `externalAnimations`，记录目标行、片段、时长和源文件 SHA-256，不记录本机路径。
- VRMA 源文件只在工坊当前会话中保留，不随角色库或备份包保存。

从上述源码提交执行 `npm run package` 成功，TypeScript 检查、Vite 构建和 Electron Windows x64 打包通过。本次发布未运行测试套件或 `npm run verify:desktop`，也未执行打包后 EXE 冒烟。真实 VRMA/VRM 的动作语义、循环接缝、遮挡和裁切仍待人工验收；用户桌面验收前应从当时源码运行 `npm run verify:desktop` 并使用对应 EXE。
