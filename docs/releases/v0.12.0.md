# OiGptPet 0.12.0 本地检查点

本地源码提交：`861a4d1`（分支 `codex/desktop-prototype`）。本轮没有推送 GitHub，也没有创建 GitHub Release。

## 更新内容

- 保留原来的 VRM“基础律动”作为默认选项，新增“怦然心动风格”和“猫步轻悄风格”两套原创八拍编排，按节拍平滑过渡。新编排借用用户指定歌曲的整体氛围，不逐帧复制原演出舞蹈。
- 新增 100 BPM、8 拍的“试听舞步”；可预览内置 VRM 舞步或已载入的精灵图舞蹈条带，不请求系统音频权限。
- 精灵图桌宠可下载 4、8、16、21 帧 SVG 模板。绘制层和参考线组分离，PNG 导出前需隐藏参考线。
- 版本号升至 0.12.0。现有音乐回环权限、VRMA 外部动作和精灵图主图集格式保持原有边界。
