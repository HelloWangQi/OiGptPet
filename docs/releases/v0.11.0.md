# OiGptPet 0.11.0

GitHub 正式 Release 已发布：[OiGptPet v0.11.0](https://github.com/HelloWangQi/OiGptPet/releases/tag/v0.11.0)。Release 对应源码提交 `c21fc4f56ef007224678b64183678b7947edb3cb`。

## 更新内容

- 工坊支持在同一会话中组合多个 VRMA 文件里的动作片段，并分配到不同图集动作行。
- 分配清单可直接预览指定动作；来源列表显示文件序号和大小，工坊显示动作库总占用。
- 导入或切换来源时锁定相关操作；导出模块独立检查单文件 64 MiB 和动作库 256 MiB 上限。
- 导出报告按动作行记录来源 SHA-256，不写本机文件路径；未分配行保留内置动作。

## 构建与验收状态

TypeScript 检查、Vite 构建与 Electron Windows x64 打包成功。两次运行 `npm run verify:desktop` 都在 VRMA 播放速度冒烟断言处失败：一次半速读数为 0 ms，另一次双倍速读数为 0 ms。失败截图稍后显示时间轴已前进，说明采样时序可能不稳定，但速度检查仍未通过，不能视为完整验收。测试套件 `npm test` 未运行。

实际麦克风、Windows 系统朗读，以及真实 VRMA/VRM 的动作语义、循环接缝、遮挡和裁切仍需人工检查。
