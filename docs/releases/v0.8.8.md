# OiGptPet 0.8.8 Preview · 掩面和托腮落点适配

本地开发版本，尚未推送或发布。

- 失落动作的双手按当前模型头颈位置和比例靠近脸部，改善肩宽差异导致双手停在胸前的问题。
- 认真工作动作的右手靠近下巴侧面，保留左臂程序姿态；实时桌宠与导出共用适配路径。
- 缺少头颈锚点或完整手臂链时保留对应的原姿态；其他动作继续使用原有角度，不引入按角色名称区分的规则。

使用固定次数、逐步限幅的手臂目标求解，每帧从当前程序姿态重新计算，避免跨帧累积。此适配不包含手指姿势、手掌方向、关节活动范围或衣袖碰撞求解；宽袖角色仍可能遮挡脸部，完整连续视觉验收需按角色进行。

34 文件、408 项单元测试通过，覆盖旋转/缩放、目标落点、不可达/非法目标和降级。两种独立模型已通过 v1/v2 导出、取消后确定性与资源释放，并查看失落/工作关键帧前后对比。
