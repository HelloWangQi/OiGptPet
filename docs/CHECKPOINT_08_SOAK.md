本轮完成的是指定软件环境下的满小时功能/采样检查；它不消除 0.8.1 的历史复核记录，也不证明任意设备永无泄漏。后续应做相同负载的实际 GPU 对照或更长时间的池化/回收观察，再判断 GPU 趋势。真实账户、多屏/DPI/休眠、硬件耗电和 ChatGPT 官方宠物安装仍未验收。
