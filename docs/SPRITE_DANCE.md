# 精灵图桌宠音乐舞步

## 目标与边界

让桌面精灵图角色在检测到系统音乐时播放用户提供的舞蹈帧，同时保持 ChatGPT 宠物所需的固定图集行和角色包格式不变。舞蹈帧是单独导入的临时 PNG；不写回主精灵图、不进入角色备份，也不上传。

音乐采集沿用 [桌面音乐舞动](MUSIC_DANCE.md) 的 Windows loopback 用户授权和窗口可见性规则。此功能只在 Electron 桌面宠物中工作；工坊预览、浏览器预览和 ChatGPT 宿主不采集系统音乐。

## 舞蹈帧 PNG 格式

- 一张 PNG 横向排列 2 到 21 帧；每帧严格为 192×208 像素，帧间不留空隙。
- 文件不得超过 20 MiB。每帧都必须至少含一个可见像素；透明背景适合叠加在精灵图桌宠窗口上。
- 序列按 4 个检测节拍循环播放。程序使用当前帧 alpha 遮罩处理桌宠点击命中。
- 导入仅在当前桌宠会话生效。换角色或关闭应用后需要重新载入。

## 当前实现

- 桌宠切换到精灵图后，可导入单独舞蹈条带；节拍信号驱动条带帧播放，音乐淡出时通过短交叉淡化返回原精灵图待机动作。
- 文件先完整解码和检查再替换现有条带。取消导入、切换角色和清除时使未完成的导入失效。
- 主精灵图、九个目标动作行、视线图集、角色库和 ChatGPT 导出均不包含舞蹈条带。

## Windows 人工验收

- 使用 2、4、8、21 帧 PNG；分别尝试错误高度、宽度不整除、空帧、非 PNG、超大文件和无效图片，确认报错清楚且当前已载入角色保留。
- 音乐开始和停止时检查 4 拍循环、动作淡入淡出与待机恢复；验证动作、聊天和手动交互期间舞蹈帧不会盖住优先动作。
- 在跳舞、切换角色、清除条带和关闭窗口时检查透明点击、拖动、穿透、采集停止和资源释放。
- 重启并重新打开精灵图桌宠，确认舞蹈条带不会被误认为持久化的角色素材。
- 按 [音乐舞动清单](MUSIC_DANCE.md#windows-人工验收清单)另外检查真实系统音频、设备切换和麦克风/系统朗读边界。

自动构建通过不代替真实 Windows 音频、画面质量与拖动体验验收。
