# 阶段三检查点：0.3.0

日期：2026-10-23。分支 `codex/desktop-prototype`，阶段基线 `402bbf8`。本次由 Codex 与外部 DeepSeek 在共享目录按文件范围协作；用户确认 DeepSeek 已完成收尾，停止新增功能，统一检查、提交与推送。

## 交付

- 设置持久化：小/标准/大三档大小，画质/均衡/省电模式，窗口同步、无效输入拒绝、损坏配置回退与失败重试。active/idle 绘制上限分别为 60/30、30/12、15/5 fps，隐藏时跳过绘制；实际能耗未作为已测成果。
- 本地角色库：VRM 和 v1/v2 PNG/WebP，稳定字节摘要身份、改名、选中、移除非当前项，默认 12 条/256 MiB。独立 IndexedDB 存原始 Blob，事务完成后报告成功，容量/并发/失败保持一致。
- 旧数据迁移：Electron 从旧 `current.vrm` 读取，浏览器从旧 `oigptpet/models/current` 读取，再交新库原子迁移。成功保留旧数据，不重复创建或覆盖已有选择/名字。
- 精灵图桌宠：完整单格 contain 绘制、九种动作和 v2 十六方向，alpha >=8 命中；DPR/缩放、取消、并发加载和迟到 Bitmap 释放。
- 主程序集成：候选画布先完成加载/静态和摘要检查，库激活成功后替换旧画布；失败/取消保留当前角色，跨窗口同步，重启恢复。精灵图源不能冒充 VRM 导出。
- 修复 DeepSeek D18 发现的布局缺陷：新候选画布清除旧 sprite inline 宽高，VRM 随容器缩放。补单测，并将实际浏览器尺寸跟随纳入 smoke 断言。
