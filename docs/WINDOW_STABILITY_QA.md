# 阶段五窗口稳定性检查矩阵

2026-11-02。用户确认 DeepSeek 不再参与，本轮由 Codex 实现和自查，不称为独立第三方复核。

## 代码边界复核

- 窗口尺寸和 workArea 都由 Electron 提供逻辑坐标，不再次乘 scaleFactor。
- 有位置时使用当前偏好尺寸选择相交显示器，坏位置回退主屏；恢复使用回调执行时实际位置，不使用过期磁盘记录。
- 屏幕增加/移除/指标变化共用防抖，resume 延迟重新检查；销毁窗口或退出后忽略恢复。监听器和恢复计时器在退出时释放。
- 自动恢复只 setBounds，不 show/focus；手动找回才显示并恢复互动。
- 写入队列复制输入、串行原子替换；正常退出等待最后一份位置，读写失败可见，旧文件保留。
- Windows 可能对窗口最小尺寸/工作区作额外调整，极小工作区与高 DPI 仍需下表实机验证。
